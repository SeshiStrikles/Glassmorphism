# 🌐 Glassmorphism Premium Subscription Page

Премиальный шаблон страницы подписки для **Remnawave** (и других VPN/Proxy панелей).
Выделяйтесь среди конкурентов благодаря современному Glassmorphism-дизайну с плавной анимацией и встроенным движком визуальных эффектов. Шаблон отображает статус пользователя, доступный трафик, ссылки на конфигурации и гайды по установке.

## ✨ Возможности

- **Glassmorphism UI:** Эффект матового стекла (размытие фона, полупрозрачные элементы, лёгкие тени).
- **Плавные анимации:** Карточки красиво выплывают при загрузке страницы (*staggered fade-up*).
- **Встроенные визуальные эффекты (FX):** Пользователь может выбрать фон в настройках (🌸 Сакура, 🌌 Северное сияние, ✨ Боке).
- **Интро-анимация:** Эффектное появление логотипа или названия при открытии страницы.
- **Поддержка тем:** Автоматическое переключение между светлой и тёмной темой, а также ручной выбор.
- **Генерация QR-кодов:** Встроенный генератор для быстрого импорта подписки.
- **Telegram WebApp Ready:** Полная совместимость с открытием внутри встроенного браузера Telegram.[^1][^2]

## 📥 Установка в одну команду

Скачайте шаблон напрямую на ваш сервер, используя `curl` или `wget`. Находясь в нужной директории вашей панели, выполните одну из команд:

**Через curl:**

```bash
curl -O https://raw.githubusercontent.com/SeshiStrikles/Glassmorphism/main/index.html
```

**Через wget:**

```bash
wget https://raw.githubusercontent.com/SeshiStrikles/Glassmorphism/main/index.html
```

## 🎨 Как изменить наименование бренда

Название бренда отображается в интро-анимации (при загрузке) и в шапке сайта. Чтобы изменить его на своё:

1. Откройте скачанный `index.html` в любом редакторе (например, `nano index.html`).
2. Найдите следующий блок в HTML-разметке:

```html
<div class="intro-logo"><span>REVERCENT</span></div>
```

3. Замените `REVERCENT` на название вашего проекта.

Дополнительно, если у вас нет внешнего конфига, измените заголовок в шапке:

1. Найдите функцию `updateBranding()` в `index.html`.
2. Внутри функции найдите строку:

```javascript
titleSpan.textContent = branding.title || 'Subscription';
```

3. Замените `'Subscription'` на нужное название, например `'MyVPN'`.

> Если ваша панель использует внешний конфигурационный файл `.app-config-v2.json`, название бренда может подтягиваться автоматически из него.

## 🔗 Как изменить Redirect Page на свой

Для обхода блокировок при открытии ссылок в Telegram используется страница-редирект. Чтобы заменить её на свой домен:

1. Откройте `index.html` в редакторе.
2. Найдите функцию `openSubscriptionUrl(url)`.
3. Внутри неё найдите константу:

```javascript
const REDIRECT_BASE = 'https://seshistrikles.github.io/redirect-page-for-miniapp/?redirect_to=';
```

4. Замените URL на ссылку вашей страницы-редиректа, например:

```javascript
const REDIRECT_BASE = 'https://ваш-домен.com/redirect/?url=';
```


Теперь все переходы будут выполняться через ваш собственный редирект-домен.[^3]

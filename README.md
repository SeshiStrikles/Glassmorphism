# 🌐 Glassmorphism Premium Subscription Page

Премиальный шаблон страницы подписки для **Remnawave** (и других VPN/Proxy панелей). Выделяйтесь среди конкурентов благодаря современному Glassmorphism-дизайну с плавной анимацией и встроенным движком визуальных эффектов. Шаблон отображает статус пользователя, доступный трафик, ссылки на конфигурации и гайды по установке.

## ✨ Возможности

- **Glassmorphism UI:** Эффект матового стекла (размытие фона, полупрозрачные элементы, легкие тени).
- **Плавные анимации:** Карточки красиво выплывают при загрузке страницы (Staggered Fade-Up).
- **Встроенные визуальные эффекты (FX):** Пользователь может выбрать фон в настройках (🌸 Сакура, 🌌 Северное сияние, ✨ Боке).
- **Интро-анимация:** Эффектное появление логотипа/названия при открытии страницы.
- **Поддержка тем:** Автоматическое переключение между светлой и темной темой, а также ручной выбор.
- **Генерация QR-кодов:** Встроенный генератор для быстрого импорта подписки.
- **Telegram WebApp Ready:** Полная совместимость с открытием внутри встроенного браузера Telegram.
